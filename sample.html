02 — Halaman tidak muncul kaku

Animasi Masuk: Fade-in & Slide-up

Pasang konfigurasi ini di <head> (setelah Tailwind CDN). Lalu pakai animate-fade-in-up untuk hero dan animate-fade-in-right untuk sidebar/teks pengantar.

TAILWIND CONFIG — KLIK SALIN 
<script src="https://cdn.tailwindcss.com"></script>
<script>
  tailwind.config = {
    theme: {
      extend: {
        animation: {
          'fade-in-up': 'fadeInUp 0.6s ease-out forwards',
          'fade-in-right': 'fadeInRight 0.6s ease-out forwards',
          'float': 'float 3s ease-in-out infinite',
          'shake': 'shake 0.5s ease-in-out',
        },
        keyframes: {
          fadeInUp: {
            '0%': { opacity: '0', transform: 'translateY(20px)' },
            '100%': { opacity: '1', transform: 'translateY(0)' }
          },
          fadeInRight: {
            '0%': { opacity: '0', transform: 'translateX(-20px)' },
            '100%': { opacity: '1', transform: 'translateX(0)' }
          },
          float: {
            '0%, 100%': { transform: 'translateY(0)' },
            '50%': { transform: 'translateY(-10px)' }
          },
          shake: {
            '0%, 100%': { transform: 'translateX(0)' },
            '20%, 60%': { transform: 'translateX(-8px)' },
            '40%, 80%': { transform: 'translateX(8px)' }
          }
        }
      }
    }
  }
</script>

Prompt A — Kartu grid + hover halus

Dan tolong, semua kartu di grid harus responsif dan memiliki animasi hover yang halus (menggunakan Tailwind hover:-translate-y-1 hover:shadow-lg transition-all duration-300).

Prompt B — Status ping + sensasi klik tombol

Tambahkan visualisasi 'status aktif' yang interaktif menggunakan animasi animate-ping pada bagian header/indikator dashboard agar terasa hidup.

Untuk tombol checkout/proses, pastikan ada transisi active:scale-95 agar ada sensasi klik yang alami (micro-interaction).

Prompt C — Upgrade file lama tanpa merusak logika ⭐

Ini adalah file index.php saya yang sudah jalan. Tolong bantu saya menyisipkan animasi masuk (fade-in-up) menggunakan konfigurasi custom keyframes di config Tailwind CDN-nya, serta berikan efek mikro-interaksi (hover, transition, active scale) pada kartu dan tombol yang ada agar estetikanya jauh lebih premium. Jangan mengubah fungsi dan logika PHP yang ada!

Prompt D — Bonus reveal + zoom + float + shake ✨

Tambahkan 4 animasi bonus yang ringan: (1) reveal on scroll dengan IntersectionObserver + class .reveal/.visible + delay bertahap, (2) image zoom hover dengan group overflow-hidden + group-hover:scale-110 duration-500, (3) float lembut custom keyframe float 3s infinite untuk ikon hero, (4) shake validasi custom keyframe shake untuk input salah. Jangan pakai library tambahan, tetap Tailwind CDN.

Prompt E — Chart + infografis CDN 📊

Tambahkan infografis animasi via CDN tanpa memberatkan: (1) Chart.js bar chart penjualan + doughnut favorit dengan animasi bawaan + tombol acak data yang memicu chart.update(), (2) 3 kartu statistik dengan count-up angka saat masuk viewport via IntersectionObserver, (3) demo Animate.css dengan pilihan efek + tombol Mainkan. CDN: animate.css 4.1.1 cdnjs + chart.js 4.4.1 jsdelivr. Tetap responsif + Tailwind.

Prompt F — SweetAlert2 popup 🍬

Ganti semua alert/confirm bawaan dengan SweetAlert2 via CDN (sweetalert2@11 jsdelivr): (1) popup sukses dengan icon success + animasi zoomIn/zoomOut dari Animate.css, (2) konfirmasi hapus dengan showCancelButton + confirmButtonColor merah, (3) toast kecil top-end timer 2000ms, (4) loading dengan Swal.showLoading() + timer 2000ms lalu sukses. Tetap pakai Bahasa Indonesia.
Tips lomba: jangan berlebihan. Cukup hover lift + fade-in-up + satu ping + satu loading — web langsung terasa premium dibanding peserta yang statis, tanpa mengorbankan performa.
