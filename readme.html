Portal Gizi & Kesehatan Remaja

Halaman utama dengan Hero Section, grid kartu artikel, dan kalkulator BMI mini.

Prompt

Warna: Gunakan palet warna yang segar dan energik (Teal / teal-500, Putih bersih, dan sedikit aksen Orange).
Nuansa: Modern, clean, dan ramah Gen-Z.

Komponen UI: Buat Hero Section dengan Call to Action "Cek Status Gizimu", diikuti dengan Grid System (3 kolom di desktop, 1 di mobile) untuk menampilkan kartu artikel kesehatan dengan efek hover yang halus (hover:-translate-y-1 hover:shadow-lg).

Inovasi Wajib:
Tambahkan satu seksi interaktif berupa desain UI "Kalkulator BMI Mini" (input tinggi & berat badan) di halaman tersebut yang terlihat estetik.

LANGKAH

Tips Eksekusi Cepat Saat Lomba

Setelah Anda mendapatkan hasil dari prompt di atas, Anda sudah mengamankan tampilan UI/UX yang solid (Vibe 30%). Selanjutnya, pecah kode tersebut menjadi prompt lanjutan yang jauh lebih pendek.

Masalah paling sering menjatuhkan peserta

Masalah AI kehilangan konteks (halusinasi) di tengah proses coding adalah hal yang paling sering menjatuhkan peserta dalam kompetisi AI coding. Untuk menjaga Skor Kualitas Prompt (25%) dan Fungsionalitas (25%), prompt debugging Anda tidak boleh hanya berbunyi “Tampilannya error, tolong perbaiki”.

Anda harus selalu menyertakan Konteks Ulang + Gejala + Log Error/Kode Tersangka.

A

Prompt Lanjutan: memecah kode jadi backend

Prompt
Bagus, sekarang berikan saya kode PHP native untuk memproses input Kalkulator BMI di dalam form tersebut, gunakan nama file hitung.php
B

Prompt Lanjutan: kode terpotong di tengah jalan

Gemini biasanya berhenti mengetik di tengah (batas panjang respon). Balas dengan perintah ini agar kode tidak rusak saat di-copy.

Prompt
Lanjutkan kodemu yang terpotong mulai dari baris <div class="..." agar kode tidak rusak saat di-copy.

Suntik Konteks

Saat AI Benar-Benar Lupa Ingatan

Terkadang jika chat sudah terlalu panjang, Gemini tiba-tiba memberikan kode dalam bahasa Python, React, atau framework lain yang tidak Anda minta. Gunakan prompt “Teguran Halus” ini.

Prompt
STOP. Kamu kehilangan konteks.

Ingat kembali aturan proyek kita:
- Kita HANYA menggunakan PHP Native untuk backend.
- Kita HANYA menggunakan HTML5 murni dan Tailwind CSS via CDN untuk frontend.
- Database kita adalah MySQL.
- Jangan menggunakan React, Node.js, atau framework lain.

ATURAN

Golden Rules Saat Debugging dengan Gemini

Aturan sederhana yang mencegah AI menulis ulang seluruh halaman Anda dengan gaya berbeda.

  • Jangan kirim seluruh isi file (ribuan baris). Kirimkan hanya blok fungsi PHP atau blok HTML (<div id="target">…</div>) yang bermasalah.
  • Mengirim kode terlalu panjang membuat AI “pusing” dan memperbesar risiko dia menulis ulang seluruh halaman dengan gaya yang berbeda, yang akan merusak desain Anda sebelumnya.

SENJATA

5 Senjata Prompt Siap Pakai

Persiapan matang adalah kunci. Simpan prompt ini di Notepad atau VS Code agar besok tinggal copy-paste dan sesuaikan bagian di dalam kurung siku […]. Kumpulan ini mencakup seluruh siklus pengembangan aplikasi, dari database hingga fitur inovatif.

1
Fungsionalitas · 25%

Arsitektur & Keamanan Database

Gunakan prompt ini di awal setelah Anda mendapat tema. Memberikan fondasi backend yang solid dan aman.

Prompt
Bertindaklah sebagai Senior Backend Developer. Saya sedang membangun aplikasi [Sebutkan Nama Aplikasi/Tema] menggunakan PHP Native dan basis data MySQL.

Tugas:
1. Buatkan skrip SQL (.sql) lengkap untuk membuat database dan 3 tabel utama yang saling berelasi, beserta dummy data (minimal 3 baris per tabel).
2. Buatkan file koneksi.php menggunakan pendekatan yang aman (disarankan PDO atau MySQLi dengan Prepared Statements).

Batasan: Pastikan tipe data efisien (misal: gunakan INT untuk ID, VARCHAR secukupnya, TIMESTAMP untuk waktu input). Sertakan komentar penjelasan di setiap baris penting.
2
Desain & Fungsi · 55%

Integrasi CRUD ke UI Tailwind

Seringkali AI membuat logika PHP yang bagus, tapi merusak desain Tailwind Anda. Gunakan prompt ini untuk menyatukan keduanya dengan rapi.

Prompt
Tugas: Buatkan proses CRUD (Create, Read, Update, Delete) menggunakan PHP Native untuk modul [Sebutkan Modul, misal: Data Produk / Data Pasien].

Spesifikasi:
- Saya sudah memiliki template UI menggunakan Tailwind CSS via CDN.
- Berikut adalah kode HTML untuk tabel/grid penampil datanya:

HTML
[PASTE KODE HTML TAILWIND ANDA DI SINI]

Tolong sisipkan logika looping while PHP dari database (MySQLi) langsung ke dalam elemen HTML tersebut agar data dinamis muncul tanpa merusak kelas Tailwind yang sudah ada. Berikan kode lengkap yang siap jalan.
3
Nilai Teknis Juri

Keamanan Anti-Hack

Juri teknis sangat menyukai peserta yang memikirkan keamanan, meskipun aplikasinya sederhana. Eksekusi ini setelah fitur utama berjalan.

Prompt
Konteks: Saya memiliki file proses_simpan.php berikut yang menangani input form dari user.

PHP
[PASTE KODE PHP PROSES SIMPAN ANDA DI SINI]

Tugas: Tolong modifikasi kode PHP tersebut agar sepenuhnya aman dari celah SQL Injection dan XSS (Cross-Site Scripting). Gunakan Prepared Statements (bind_param) dan fungsi sanitasi bawaan PHP seperti htmlspecialchars(). Jangan ubah nama variabel POST yang datang dari form.
4
Inovasi & Kreativitas · 20%

Prompt

Tugas:
1. Buatkan kode HTML/JS menggunakan library Chart.js via CDN.

3. Grafik ini harus menampilkan data: [Sebutkan datanya, misal: Jumlah panen per bulan / Kategori produk terlaris].
4. Berikan juga contoh skrip PHP sederhana di atasnya untuk mengambil data dari tabel MySQL agar array datanya dinamis masuk ke dalam Chart.js.

SKOR

Taktik Pamungkas per Kriteria

Untuk menyapu bersih poin berdasarkan bobot kriteria tersebut, eksekusi Anda harus sangat terukur. Karena Desain Visual & Vibe memegang porsi terbesar (30%), diikuti Kualitas Prompt (25%) dan Fungsionalitas (25%), strategi prompting Anda harus langsung membidik keempat aspek ini secara simultan.

Desain Visual & Vibe 30%

Kunci warna sejak prompt pertama, integrasikan aset PNG, dan tambahkan efek premium.

Kualitas Prompt 25%

Log prompt bernomor fase + constraint prompting yang tegas.

Fungsionalitas 25%

Navigasi tanpa tombol mati, dan responsivitas mobile-first.

Inovasi & Kreativitas 20%

Visualisasi data + lapisan keamanan ekstra.

1
Bobot 30%

Desain Visual & Vibe

Kriteria ini menilai estetika, konsistensi, dan kesesuaian tema. Jangan biarkan Gemini memilih warna secara acak.

Prompt — Palet Warna Spesifik
Kunci warna sejak prompt pertama. Jika mendapat tema Kesehatan, instruksikan: "Gunakan palet warna trust & health: background bg-slate-50, primary button bg-teal-600 hover:bg-teal-700, dan text text-slate-800". Konsistensi kelas Tailwind ini bernilai tinggi.
Prompt — Integrasi Aset Kustom
UI yang hanya berisi teks akan terlihat membosankan. Siapkan beberapa ikon atau logo berformat PNG transparan (tanpa background) malam ini. Saat me-prompt Gemini untuk membuat Navbar atau Hero Section, instruksikan: "Sediakan tag <img src='assets/logo.png'> di bagian kiri Navbar dengan ukuran w-12 h-12". Ini langsung mendongkrak estetika visual.
Prompt — Kesan "Modern"
Selalu tambahkan instruksi vibe seperti "Gunakan efek soft shadow (shadow-md) pada setiap kartu produk dan tambahkan transisi halus (transition duration-300 ease-in-out hover:-translate-y-1) saat kartu di-hover" untuk memberikan nuansa premium.
2
Bobot 25%

Fungsionalitas

Juri akan menguji kelancaran fitur, navigasi antar halaman, dan responsivitas di berbagai layar.

Prompt — Navigasi Mulus
Jangan biarkan ada tombol mati. Instruksikan: "Pastikan semua menu di Sidebar memiliki tautan yang berfungsi (misal href='index.php?page=dashboard'), jangan gunakan href='#'."
Prompt — Kunci Responsivitas (Mobile-First)
Periksa kembali kode Tailwind di atas. Pastikan layout grid berubah menjadi 1 kolom (grid-cols-1) di layar mobile (<768px) dan 3 kolom (md:grid-cols-3) di desktop. Berikan kode perbaikannya jika ada yang belum responsif.
3
Bobot 25%

Kualitas Prompt

Penilaian berfokus pada efektivitas dan kreativitas Anda dalam berkomunikasi dengan AI. Juri sangat menyukai peserta yang bisa mengendalikan AI, bukan dikendalikan AI.

Prompt — Format Log Profesional
Saat menyalin log prompt ke dokumen penyerahan, jangan hanya di-paste mentah-mentah. Berikan judul fase (misal: Fase 1: Inisialisasi Database, Fase 2: Pembuatan UI Tailwind).
Prompt — Constraint Prompting
Buatkan proses input data. BATASAN: Jangan gunakan alert JavaScript bawaan, gunakan alert komponen Tailwind CSS yang muncul di atas form. Jangan ubah struktur tabel database yang sudah disepakati di prompt sebelumnya.
4
Bobot 20%

Inovasi & Kreativitas

Anda butuh keunikan ide dan fitur tambahan untuk mendukung hasil akhir dan mengunci skor ini. Aplikasi sederhana sering kali melupakan keamanan.

Prompt — Fitur Analitik (Visualisasi Data)
Daripada sekadar menampilkan data panen atau penjualan UMKM dalam bentuk tabel biasa, instruksikan Gemini: "Integrasikan Chart.js via CDN. Buatkan satu grafik bar (Bar Chart) interaktif yang merangkum total data dari tabel MySQL ini." Visualisasi grafik selalu dianggap sebagai fitur level lanjut (advanced) oleh juri.
Prompt — Keamanan Ekstra (Security)
Terapkan keamanan Anti-XSS (Cross-Site Scripting) menggunakan htmlspecialchars() dan cegah SQL Injection menggunakan Prepared Statements pada semua form input PHP ini. Menulis hal ini di log prompt membuktikan pemahaman sistem tingkat tinggi.
CHECKLIST

Saran Eksekusi Ekstra

Langkah praktis sebelum dan selama lomba, termasuk struktur folder yang perlu siap di Laragon.

Persiapan malam sebelum lomba

  • Jalankan Laragon, buat folder khusus (misal: htdocs/lomba-vibe), dan buka di code editor.
  • Siapkan folder assets/ untuk logo/gambar pendukung (PNG transparan) — jangan membuang waktu mengatur direktori saat lomba sudah berlangsung.
  • Simpan dokumen ini di Notepad atau VS Code agar tinggal copy-paste.

Selama lomba

  • Selalu catat prompt yang Anda gunakan di log_prompt.txt agar saat juri meminta bukti komunikasi (Skor Log Prompt 25%) Anda bisa menunjukkan struktur prompt yang sangat profesional dan sistematis.
  • Kunci warna di prompt pertama; di akhir setiap sesi pembuatan halaman, gunakan prompt validasi responsivitas.
  • Debugging: kirim potongan kode, bukan seluruh file.

Isi Presentasi (slide):
1. Slide Judul — nama aplikasi, nama kelompok, dan tagline singkat.
2. Slide Latar Belakang — masalah nyata yang diselesaikan aplikasi ini.
3. Slide Fitur Utama — 3–4 fitur utama, masing-masing dengan ikon dan satu kalimat penjelasan.
4. Slide Tampilan Aplikasi — deskripsi atau screenshot tiap halaman penting, sertakan nama file-nya.
5. Slide Data — tampilkan statistik ringkas dari database (jumlah data, rata-rata, dan nilai tertinggi) sebagai angka besar yang menarik.
6. Slide Teknologi — daftar stack yang dipakai (PHP Native, MySQL, Tailwind CSS, Chart.js) beserta alasan singkat выборnya.
7. Slide Keamanan — Prepared Statements anti SQL Injection, sanitasi htmlspecialchars() anti XSS.
8. Slide Penutup — terima kasih dan ajakan demo.

Aturan Animasi (WAJIB, agar terasa seperti slide PowerPoint):
- Setiap slide muncul dengan transisi masuk yang halus, staggered (judul muncul lebih dulu, lalu subjudul, lalu bullet satu per satu dengan jeda). Gunakan CSS @keyframes + animation-delay, atau kelas Tailwind animate- dengan delay bertahap.
- Transisi antar slide: gunakan fade + slide, atau zoom-in dengan durasi 400–700ms dan easing ease-out. Jangan gunakan transisi yang terlalu cepat atau norak.
- Bullet list masuk dengan animasi staggered (misal setiap bullet delay 80–120ms dari bullet sebelumnya).
- Angka pada slide Data sebaiknya memiliki animasi count-up saat slide tersebut muncul.
- Hormati prefers-reduced-motion: matikan semua animasi bila pengguna mengaktifkannya.

Aturan Navigasi & Interaksi:
- Navigasi dengan tombol “Slide Sebelumnya” dan “Slide Berikutnya”, serta support tombol panah kiri/kanan pada keyboard.
- Tampilkan indikator nomor slide (misal “3 / 8”) dan progress bar di bawah.
- Tambahkan transisi saat berpindah slide (tidak boleh langsung kasar cut).

Batasan:
- Satu file presentasi.html saja (CSS dan JS ditulis inline di dalam file tersebut), tidak boleh dependensi file lain di luar folder ini, dan boleh memakai CDN untuk Tailwind, FontAwesome, dan Chart.js.
- Jangan gunakan framework seperti React, Vue, atau Node.js.
- Jangan mengubah atau merusak file aplikasi asli yang sudah jadi; file presentasi berdiri sendiri sebagai pelengkap.
- Gunakan palet warna dan vibe yang konsisten dengan aplikasi utama: [Sebutkan palet warna aplikasi, misal: teal-600, slate-800, white].
- Pastikan tampilannya tetap rapi dan responsif di laptop maupun proyektor.

Berikan kode lengkap presentasi.html yang siap jalan, beserta satu paragraf penjelasan singkat cara membukanya di browser.
