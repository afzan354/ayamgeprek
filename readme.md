# 🍗 Ayam Geprek

Website sederhana bertema **Ayam Geprek**, ayam goreng tepung renyah yang digeprek (dipukul/ditekan) bersama sambal cabai rawit pedas.

🔗 **Demo:** [https://geprek.free.nf/](https://geprek.free.nf/)

---

## 📖 Tentang Ayam Geprek

Ayam geprek adalah makanan khas Indonesia yang populer, terutama di Yogyakarta. Ayam goreng tepung yang garing diletakkan di atas cobek, lalu digeprek bersama sambal bawang dan cabai rawit hingga bumbunya meresap ke setiap lekuk ayam.

Biasanya disajikan dengan:

- Nasi putih hangat
- Lalapan (timun, kol, tomat)
- Tahu atau tempe goreng
- Es teh manis sebagai penyeimbang rasa pedas

## 🚀 Cara Menjalankan

1. Clone repositori ini:
   ```bash
   git clone https://github.com/afzan354/ayamgeprek.git
   ```
2. Masuk ke folder proyek:
   ```bash
   cd ayamgeprek
   ```
3. Buka `index.html` di browser, atau jalankan lewat web server lokal seperti Laragon.
