💡 Tips Eksekusi Cepat Saat Lomba:
Setelah Anda mendapatkan hasil dari prompt di atas, Anda sudah mengamankan tampilan UI/UX yang solid (Vibe 30%).

Selanjutnya, pecah kode tersebut. Prompt berikutnya cukup seperti: "Bagus, sekarang berikan saya kode PHP native untuk memproses input Kalkulator BMI di dalam form tersebut, gunakan nama file hitung.php".

Jika Gemini berhenti mengetik kode di tengah jalan (biasanya karena batas panjang respon), langsung balas dengan perintah: "Lanjutkan kodemu yang terpotong mulai dari baris <div class="..." agar kode tidak rusak saat di-copy.

Masalah AI kehilangan konteks (halusinasi) di tengah proses coding adalah hal yang paling sering menjatuhkan peserta dalam kompetisi AI coding. Untuk menjaga Skor Kualitas Prompt (25%) dan Fungsionalitas (25%), prompt debugging Anda tidak boleh hanya berbunyi "Tampilannya error, tolong perbaiki".

Anda harus selalu menyertakan Konteks Ulang + Gejala + Log Error/Kode Tersangka.

Berikut adalah template prompt debugging jitu yang bisa Anda salin-tempel besok saat menghadapi masalah:

1. Prompt Debugging UI/UX (Tampilan Berantakan)
   Biasanya terjadi karena class Tailwind ada yang konflik, struktur div ada yang belum tertutup, atau efek responsif (mobile-desktop) gagal berfungsi.

Konteks: Ingat, kita sedang membangun antarmuka [Sebutkan Nama Halaman, misal: Katalog Produk UMKM] menggunakan murni HTML dan Tailwind CSS via CDN. Tidak ada CSS eksternal.

Masalah: Tampilannya berantakan. [Jelaskan spesifik, misal: Bagian grid kartu produk malah menumpuk ke bawah (stacked) di layar laptop, padahal seharusnya sejajar 4 kolom ke samping. Selain itu, tombol 'Beli' ukurannya jadi terlalu besar.]

Kode Saat Ini:

HTML
[PASTE KODE HTML BAGIAN YANG BERANTAKAN SAJA DI SINI, BUKAN SELURUH HALAMAN]
Tugas: Tolong perbaiki class Tailwind pada elemen tersebut. Pastikan menggunakan utility class yang tepat untuk grid (grid-cols-4) dan perbaiki ukuran tombolnya agar proporsional. Berikan hanya kode yang sudah diperbaiki.

2. Prompt Debugging Logika/Fungsionalitas (Fungsi PHP/Database Gagal)
   Gunakan ini jika terjadi Fatal Error, halaman blank putih, data gagal tersimpan ke database, atau fungsi hitung-hitungan tidak muncul.

Konteks: Kita sedang mengerjakan fungsionalitas [Sebutkan Nama Fitur, misal: Simpan Data Panen Pertanian] menggunakan PHP Native dan MySQLi.

Masalah: Fungsi tidak berjalan. Saat saya klik tombol submit, [Jelaskan gejalanya, misal: data tidak masuk ke database] dan muncul pesan error berikut di browser:

Pesan Error:
[PASTE PESAN ERROR DARI BROWSER DI SINI, misal: Parse error: syntax error, unexpected '}' in...]

Kode Eksekusi:

PHP
[PASTE KODE PHP YANG MEMPROSES LOGIKA TERSEBUT DI SINI]
Tugas: Analisis penyebab error tersebut. Tolong perbaiki baris kode yang salah dengan tetap mempertahankan nama variabel ($) dan struktur tabel yang sudah ada. Jangan mengubah stack teknologi kita.

3. Prompt "Suntik Konteks" (Saat AI Benar-benar Lupa Ingatan)
   Terkadang jika chat sudah terlalu panjang, Gemini tiba-tiba memberikan kode dalam bahasa Python, React, atau framework lain yang tidak Anda minta. Gunakan prompt "Teguran Halus" ini:

STOP. Kamu kehilangan konteks.

Ingat kembali aturan proyek kita:

Kita HANYA menggunakan PHP Native untuk backend.

Kita HANYA menggunakan HTML5 murni dan Tailwind CSS via CDN untuk frontend.

Database kita adalah MySQL.

Jangan menggunakan React, Node.js, atau framework lain. Kita sedang memperbaiki fitur [Sebutkan Fitur] di file [Sebutkan Nama File]. Berdasarkan batasan ini, tolong tulis ulang solusi untuk masalah sebelumnya: [Sebutkan ulang masalahnya secara singkat].

💡 Golden Rules Saat Debugging dengan Gemini Besok:

Jangan kirim seluruh isi file (ribuan baris). Kirimkan hanya blok fungsi PHP atau blok HTML (<div id="target">...</div>) yang bermasalah. Mengirim kode terlalu panjang membuat AI "pusing" dan memperbesar risiko dia menulis ulang seluruh halaman dengan gaya yang berbeda, yang akan merusak desain Anda sebelumnya.

Jika error karena "Undefined Variable": AI sering lupa variabel apa yang dia buat 3 prompt yang lalu. Jika muncul error ini, prompt-nya: "Error undefined variable $nama_produk. Variabel ini seharusnya diambil dari metode POST form sebelumnya. Tolong perbaiki cara penangkapannya."

Persiapan yang matang adalah kunci. Untuk memastikan Anda bisa bergerak cepat dan mencetak skor maksimal besok, berikut adalah "senjata rahasia" berupa kumpulan prompt siap pakai yang mencakup seluruh siklus pengembangan aplikasi, mulai dari database hingga fitur inovatif.

Simpan prompt-prompt ini di Notepad atau VS Code Anda agar besok tinggal copy-paste dan sesuaikan bagian di dalam kurung siku [...].
